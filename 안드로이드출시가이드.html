📱 문센파인더 — 안드로이드 출시 종합 가이드

법률·보안 검토 · 출시 방법 · 상품명 · 개인정보/데이터안전 · 체크리스트 (쉬운 말)

🎯 결론 먼저

앱으로 만들 수 있습니다. 보안 구멍은 모두 막았고(XSS·CSP·SRI·개인정보), 개인정보처리방침도 준비됐습니다. 안드로이드 출시의 유일한 전제는 ‘커스텀 도메인 1개(연 1~2만원)’ — 이것만 있으면 PWABuilder로 Play 스토어 앱을 코드 거의 그대로(기능 100% 유지) 발급할 수 있습니다. 도메인 없이 당장 쓰려면 ‘홈 화면에 추가(PWA)’로도 앱처럼 설치됩니다.

이번에 처리한 보안 항목 (출시 차단급 ‘구멍’ 0)

참고 브라우저에서 코드를 즉석 번역하는 부분 때문에 소스 단계 보안정책은 일부 완화가 불가피하나, ‘미리 번역한 배포본(dist)’에는 더 엄격한 정책이 적용됩니다(이미 빌드 도입).

⚖ 2. 법률 — 출시 전 점검

🟢=완료 🟡=출시 전 확인/조치
항목상태설명
개인정보처리방침🟢 준비완료privacy.html 작성 — 단말저장·서버없음·위치 일시처리 정확 반영. Play Console에 URL 등록만 하면 됨
강좌 데이터 출처🟡 완화됨마트 문화센터 강좌를 모아 보여줌 → ‘사실정보(시간·가격)만 + 신청은 원본 링크로 연결’ 방식이라 검색 디렉터리로 방어적. 단 수익화 시 공식 제휴/공공데이터 권장
위치정보(GPS)🟡 확인필요거리계산용으로만 쓰고 저장 안 함 → 비상업이면 대체로 OK. 영리 출시 시 ‘위치기반서비스사업’ 신고 대상 가능(소상공인 1개월 유예)
제3자 지도/경로 약관🟡 확인필요무료 공개서버(Nominatim/OSRM)는 대량·상업엔 부적합 → 출시 규모 커지면 유료/자체 API 교체
상품명 상표🟡 권고‘문센파인더’는 식별력 약해 ‘주의’ → 아래 제안명으로 변경 + 출원 전 변리사 정밀검색

※ 본 검토는 AI 기반이며 법률자문이 아닙니다. 데이터 출처·위치·상표는 정식 출시 전 전문가 확인 권장.

📲 4. 안드로이드에 올리는 법 (단계별)

PWA → TWA 방식 (코드 그대로, 기능 100% 유지)
커스텀 도메인 확보 (필수)
현재 주소(github.io/culture-center-finder)는 폴더형이라 앱 신뢰검증 파일을 못 올림 → 도메인 1개 구매(예 gangjwamasil.kr, 연 1~2만원) 후 연결
▸ 도메인 구매처: 가비아/후이즈 등. GitHub Pages에 CNAME 연결
PWA 점검
앱처럼 설치되도록 manifest·아이콘·서비스워커 확인(이미 PWA 구성됨). 시작 빠르게 하려면 빌드본(dist) 배포
▸ npm run build 결과(dist) 또는 현 소스
TWA 패키징
PWABuilder(웹)에 도메인 입력 → ‘Android 패키지(AAB)’ 자동 생성. 또는 Bubblewrap CLI
▸ pwabuilder.com 접속 → URL 입력 → Generate → Android
도메인 검증 파일
PWABuilder가 준 assetlinks.json을 도메인의 /.well-known/ 에 업로드(주소창 없는 ‘진짜 앱’ 모드)
▸ TWA 신뢰모드 필수
Play Console 등록
개발자 계정($25 1회) → AAB 업로드 → 개인정보처리방침 URL(privacy.html) + 데이터안전 폼 + 콘텐츠등급 작성
▸ play.google.com/console
비공개 테스트 → 출시
개인 계정은 테스터 12명·14일 비공개테스트 후 프로덕션 신청
▸ 요건 충족 후 ‘프로덕션’ 출시

🛡 5. 개인정보처리방침 & 데이터안전(Data Safety)

개인정보처리방침: privacy.html 작성 완료 → 배포 후 그 주소를 Play Console에 등록

Google Play ‘데이터 안전’ 폼 답변 (이대로 입력하면 됩니다):

질문답변근거
데이터 수집(앱→개발자 서버)없음서버·계정 없음. 즐겨찾기·메모·후기 등은 모두 기기에만 저장
위치정보공유(일시처리)현재위치 좌표를 거리계산 위해 지도서비스(OSM/OSRM)에 일시 전달, 저장 안 함 → ‘앱 기능’ 목적으로 선언
데이터 공유(제3자)위치(지도서비스)지오코딩·경로계산 목적. 광고·판매 목적 공유 없음
암호화전송 중 암호화모든 통신 HTTPS
데이터 삭제 요청해당없음(서버데이터 없음)기기 데이터는 사용자가 직접 삭제/앱 제거로 제거
계정 생성없음로그인·회원가입 없음

✅ 6. 반드시 해야 할 것 (체크리스트)

반드시 (출시 전 필수)

  • 커스텀 도메인 구매·연결 (TWA 신뢰검증의 전제 — 이게 없으면 ‘주소창 없는 앱’ 불가)
  • Play Console에 개인정보처리방침 URL 등록 (privacy.html 배포 후 그 주소)
  • 데이터안전(Data Safety) 폼 작성 — 위치=‘공유(앱기능)’로 정확히 신고(불일치 시 거부)
  • 상품명 확정 — ‘강좌마실’ 또는 ‘문센플래너’로 변경(현재명은 등록 위험)
  • 콘텐츠 등급 설문(IARC) + 위치권한 사용 사유 명시

권장 (가급적)

  • 수익화(광고/결제) 도입 시: 지도·경로를 유료/자체 API로 교체, 위치기반서비스 신고 검토
  • 강좌 데이터는 ‘신청=원본 센터 링크’ 원칙 유지(디렉터리 포지션)
  • 상표는 변리사 정밀검색 후 ‘강좌마실’(강한권리)+‘문센플래너’(SEO) 이중 출원
  • 성능: 첫 화면 데이터(27MB) 지역별 분할 로드(체감속도 개선)

🔀 7. 앱으로 만들기 어렵다면? (대안)

기능을 빼지 않고 사용성 유지하는 선택지
PWA ‘홈 화면에 추가’ (지금 즉시·무료)

스토어 없이도 사용자가 브라우저에서 ‘홈 화면에 추가’하면 앱처럼 아이콘 설치·전체화면 실행. 도메인·심사 불필요. 가장 빠른 시작.

커스텀 도메인 + TWA (권장·진짜 Play 앱)

도메인만 있으면 PWABuilder로 Play 스토어 앱 발급 가능. 코드 거의 그대로, 기능 100% 유지.

Capacitor 래퍼 (네이티브 기능 필요 시)

푸시알림 등 네이티브가 필요하면 Capacitor로 감싸기. 단 ‘단순 웹뷰’ 거부정책 주의(가치 추가 필요).

가장 현실적: ① 지금 바로 ‘홈 화면에 추가’로 앱처럼 쓰기(무료·즉시) → ② 도메인 사서 PWABuilder로 Play 스토어 정식 등록. 둘 다 기능은 그대로입니다.
