방법 1 · 추천

홈 화면에 추가 (지금 즉시·무료)

안드로이드 폰에서
폰의 크롬 브라우저를 엽니다
아래 주소로 접속:
https://bsy522-dot.github.io/culture-center-finder/
우측 상단 ⋮(점 세 개) → ‘앱 설치’ 또는 ‘홈 화면에 추가’ 탭
홈 화면에 문센파인더 아이콘이 생깁니다 → 탭하면 앱처럼 전체화면 실행 ✅
아이폰은 사파리에서 ‘공유’ → ‘홈 화면에 추가’ 입니다.
방법 2

APK 파일 만들기 (PWABuilder, 약 10분)

‘설치파일(.apk)’을 만들어 카톡 등으로 공유하고 싶을 때 — PC에서
PC 브라우저로 pwabuilder.com 접속
가운데 칸에 주소 입력 후 Start:
https://bsy522-dot.github.io/culture-center-finder/
위쪽 Package For Stores → Android 선택 → Generate / Download
받은 .apk(또는 zip 안의 apk)를 카톡·USB로 폰에 전송
폰에서 그 파일을 탭 → ‘출처 불명 앱 설치 허용’ 켜고 설치 ✅
주의: 지금은 도메인이 없어서 앱 상단에 작은 주소줄이 보일 수 있습니다. 도메인(연 1~2만원)을 연결하면 사라지고 ‘진짜 앱’ 모드가 됩니다.
방법 3

Play 스토어 정식 등록

누구나 스토어에서 검색·설치하게 하려면

도메인 1개(연 1~2만원) + 개발자 계정($25) + 개인정보처리방침 등록이 필요합니다. 단계는 안드로이드출시가이드.html에 정리해 뒀습니다. (개인정보처리방침은 이미 라이브: .../privacy.html)

요약: 지금 폰으로 보고 싶다 → 방법 1(1분). 파일로 공유하고 싶다 → 방법 2(PWABuilder). 스토어 정식 → 방법 3(도메인 필요). 어떤 방법이든 기능은 하나도 안 빠집니다.
