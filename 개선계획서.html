지금 이런 문제가 있어요

출시 전 반드시 해결할 핵심 문제들
앱이 너무 무겁게 열림 (29MB 한 번에)
문제지금은 앱을 켜면 전국 8만 강좌 데이터(29MB ≈ 사진 100장)를 통째로 내려받아 첫 화면이 느립니다.
개선지역별로 잘게 나눠, 보고 있는 지역 것만 먼저 받게 바꿉니다.
효과첫 화면이 몇 배 빨라지고 데이터 요금도 절약됩니다.
입력한 글에 나쁜 코드가 숨겨질 수 있음
문제메모·노트·위시리스트 등에 악성 코드를 넣으면 실행될 수 있는 보안 구멍이 여러 곳 있습니다.
개선모든 입력을 자동으로 안전 처리하는 장치(짧은 코드)를 전 구간에 적용합니다.
효과개인정보 탈취·화면 변조 위험이 사라집니다.
첫 화면이 너무 복잡함 (부가버튼 45개)
문제기능을 더하면서 첫 화면에 부가기능 버튼이 45개나 떠서, 정작 핵심인 '강좌 검색'이 묻힙니다.
개선핵심(검색·시간표)만 앞에 두고, 부가기능은 한 곳(메뉴)으로 모읍니다.
효과처음 온 사람도 3초 안에 '뭐 하는 앱'인지 압니다.
추천·랭킹이 빈 데이터/가짜로 동작
문제수강 추천과 인기 랭킹이 잘못 연결돼 빈 화면이거나, 실제 8만 데이터 대신 가짜 숫자를 보여줍니다.
개선올바른 데이터에 연결하고, 랭킹은 실제 강좌 수로 계산합니다.
효과보이는 정보가 진짜가 되어 신뢰가 생깁니다.
강사 실명 18만건 노출
문제강사 실명이 공개 데이터에 그대로 들어 있어 개인정보 문제가 됩니다.
개선강사 실명만 제거(강좌명·가격·시간 등 선택에 필요한 정보는 유지). 전체 원본은 내부 보관.
효과개인정보 위험 해소 + 학부모가 고를 정보는 그대로.
중요 (이어서)

그 다음으로 고칠 것

화면 띄울 때마다 즉석 코드번역(느림)
문제앱이 매번 열릴 때 코드를 즉석에서 번역하는 무거운 도구를 씁니다.
개선미리 한 번 번역해 두는 '빌드' 단계를 만듭니다(자동·재실행 가능).
효과속도가 빨라지고 전문가 표준 배포가 됩니다.
글씨가 너무 작고 색이 흐려 안 보임
문제8~10px 작은 글씨, 흐린 회색 글자, 작은 버튼, 누른 위치 표시 없음 — 어르신·저시력엔 불편합니다.
개선글씨 키우고 색 대비를 기준(WCAG AA) 이상으로, 버튼은 손가락 크기(44px)로, 포커스 표시 추가.
효과누구나 또렷하게 보고 쉽게 누릅니다.
같은 코드가 여러 번 복붙됨
문제기본 도구 코드가 화면 곳곳에 똑같이 복사돼 있어 고칠 때 실수가 납니다.
개선공용으로 한 번만 두고 재사용하게 정리(동작은 그대로).
효과유지보수가 쉬워지고 버그가 줄어듭니다.
자동 점검·테스트가 없음
문제바뀐 게 잘 도는지 자동으로 확인하는 장치가 없습니다.
개선핵심 사용 흐름 3개를 실제 브라우저로 자동 점검하게 만듭니다.
효과바꿀 때마다 망가짐을 즉시 잡습니다.
자동 수집 데이터가 화면에 반영 안 됨
문제매일 자동으로 강좌를 모으지만, 앱이 읽는 파일과 달라 최신이 안 보일 수 있습니다.
개선수집 결과가 앱이 읽는 파일로 바로 들어가게 연결.
효과항상 최신 강좌가 보입니다.
새 기능

이왕이면 추가할 기능

⭐ 시간표 자동 만들기 (신규)
문제원하는 강좌를 담으면 요일·시간으로 주간 시간표를 자동 배치하고 겹치는 시간을 알려줍니다.
개선'피아노 화 10시 + 영어 목 3시…'를 격자 시간표로. 어느 센터도 없는 기능.
효과학부모가 한눈에 일정을 짜고, 우리 앱만의 차별점이 됩니다.

작업 순서

안전하게 한 단계씩 — 각 단계마다 저장 지점을 만들어 문제 시 되돌립니다
강사 실명 제거 (✅ 완료 — 개인정보 보호)
보안 안전장치 적용 (나쁜 코드 차단)
속도 개선 (29MB 쪼개기 + 미리 번역)
첫 화면 정리 (핵심만 앞으로) + 글씨·색·버튼 또렷하게
추천·랭킹 진짜 데이터로 + 코드 정리
시간표 기능 추가
자동 점검(테스트)·빌드·문서 갖추고 → 안전 배포
